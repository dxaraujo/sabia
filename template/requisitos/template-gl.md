# Termo (GL)

```markdown
<a definição, numa frase>

<lista ou tabela>   <!-- só quando o termo é um conjunto de valores -->

**Evitar:** <sinônimos, separados por vírgula>   <!-- só se houver --> \
**Sigla:** <sigla>   <!-- só se houver --> \
**Não confundir com:** <a mesma palavra com outro sentido, e o termo certo para ele>   <!-- só se houver -->
```

- Um termo por conceito, no singular. O slug do arquivo de `elm/` é o termo em kebab-case.
