# 2.1.32 — MCPs em versão fixa

Implementada em 11/11/2026.

O `mcp.json` subia os MCPs com `@latest`: uma versão nova de um MCP passava a valer em todo projeto sem o Sabiá ter
sido testado com ela. Agora cada MCP entra numa versão fixa, e cada versão do Sabiá roda com os MCPs com que foi
testada.

| MCP | Antes | Agora |
|---|---|---|
| `mcp-elm` | `mcp-elm@latest` | `mcp-elm@4.0.2` |
| `mcp-gitlabpr` | `mcp-gitlabpr@latest` | `mcp-gitlabpr@2.0.0` |

O `mcp-elk` fica fora do Sabiá (a pessoa o instala na ferramenta), então não entra no `mcp.json`.

Ao publicar uma versão nova de um MCP: trocar a versão no `mcp.json` e publicar uma versão do Sabiá. Um teste
recusa `@latest` no `mcp.json`.
