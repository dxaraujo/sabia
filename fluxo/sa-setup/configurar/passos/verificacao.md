## Entrada

Os tipos do projeto e os comandos do passo `comandos`.

## Faça

1. Projeto `backend` ou `frontend` → pergunte o Executar (como subir a aplicação) e a URL de teste, nunca a de
   produção. Procure antes no repositório (`.env.example`, `application-*.yml`, README).
2. Vão na seção Verificação de aceite do `sabia.md`. O `sa-verificador` exercita a aplicação direto, por curl ou
   navegador, e o curl dele fica liberado só para essa URL.
3. Projeto `batch`, `dados` ou `biblioteca` → só o Executar (job e parâmetros), sem URL.

## Saída

→ passo `autonomia`.

## Pare se

- Nunca aceite URL de produção.
